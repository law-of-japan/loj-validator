# 初期実装の検証記録

2026-11-06。Windows、Rust 1.99.1。Claude Codeが初期実装を担当し、Codexがコードレビュー・独立したCLI試験・修正後の全試験を実施した。

## 成功した確認

- `cargo fmt --all --check`
- `cargo test --workspace --locked`：33テスト関数が成功。うち意味AST試験は28入力を、マッピング・参照試験は複数の正常/異常ケースを内部で照合する。
- `cargo clippy --workspace --all-targets --locked -- -D warnings`
- chaptered-lawサンプル：構造・意味ともpassed、明示参照1件を解決。
- 独立CLI試験8入力：正常、末尾本文欠落、参照切れ、外部参照、空文書、不正プロファイル、正規表現の番号/号グループが不参加の場合。終了コードとJSON解析、パニックがないことを確認。
- 評価リポジトリの固定Law of Japan原文7ファイルを、新CLIと既定構造スキーマで読み取り実行：7件すべて両層passed。原文はこのリポジトリに複製していない。

## レビューによる修正

意味ASTがスキーマ不適合になると、検査器は関係検査を省略する。その際に、実行層がマッピング診断まで失いmapping_complete=trueを返していたケースを修正した。既に得られたマッピング診断を重複なく結果に残し、mapping_completeはマッピング自身の診断から算出する。空文書のCLI回帰試験を追加した。

Rust 1.82という宣言を、固定依存の宣言に必要な1.88へ修正した。実際に試験したツールチェーンは1.99.1であり、最小版そのものの動作試験とは区別する。

## 現時点の範囲

単一MarkdownファイルをCLIで検査する初期実装。複数ファイルの意味AST結合はライブラリAPIにあるが、CLIの一括実行機能は未実装。外部/別ファイル参照は警告とcoverageで未検証を明示する。Front Matter、複雑な法令階層、結合表の意味解釈、他版参照や法的有効性の判断は対応範囲に含めない。

Linux/macOS、Rust最小版、配布バイナリの試験は今後の作業。今回の原文7件の合格は法令一般への適合証明ではない。依存はCargo.lockで固定し、元の評価フォルダーをビルド時に参照しない。
